# DriveCare 🚗🔧
> **Care Beyond the Drive.**

**DriveCare** is a modern, high-performance **Car Servicing & Garage Booking System** built with React 19, TypeScript, Vite, and Tailwind CSS. It empowers vehicle owners with transparent pricing, instant slot booking, digital inspection estimates, and interactive 3D vehicle visualization.

## ✨ Features

- 📅 **Multi-Step Garage Booking:** Interactive slot selection, pickup & drop valet requests, vehicle specs input, and instant digital voucher generation.
- 🏎️ **Interactive 3D Red Car Model:** Embedded interactive 3D model with 360° controls and AR support powered by Google `@google/model-viewer`.
- 🛠️ **Service Catalog & Transparent Packages:** Detailed service breakdown (Mechanical, Maintenance, Diagnostics, Electrical, Detailing) with upfront transparent pricing.
- ⚡ **Master Diagnostics Flowchart:** 5-step digital service blueprint explaining the process from drive-in scan to showroom valet delivery.
- 🏢 **Workshop & Bays Gallery:** Categorized photo gallery showcasing service bays, diagnostic rigs, and certified delivery fleets.
- 📱 **Fully Responsive UI:** Optimized across all screen sizes with smooth transitions, custom scrollbars, and dark navy aesthetic.

## 🚀 Tech Stack

- **Frontend:** React 19, TypeScript
- **Bundler & Tooling:** Vite 6
- **Styling:** Tailwind CSS v4 with custom `@theme` brand tokens
- **3D Visualization:** Google `<model-viewer>` Web Component
- **Icons:** Lucide React

## 💻 Local Development

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vamsi/drivecare-automotive-service.git
   cd drivecare-automotive-service
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
